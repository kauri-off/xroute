# XRoute

Каркас Android-компаньона и модуля Vector (libxposed API 102) в одном APK. Первый адаптер обслуживает запрос последней известной GPS-позиции. Для трекеров, которые подписываются на обновления, потребуется отдельный адаптер доставки.

## Запуск

Сборка требует JDK 17 и Android SDK Platform 37.2. Команда сборки и проверки ядра — `./gradlew :app:assembleDebug :app:testDebugUnitTest`. Минимальная версия Android — 10.

1. Установите APK, включите XRoute в Vector и добавьте нужный пакет в область действия. Перезапустите целевое приложение после изменения области.
2. В XRoute укажите имя пакета. Нажимайте на карту в порядке прохождения точек. Для загрузки картографической подложки нужен интернет.
3. Задайте среднюю скорость в км/ч, выберите профиль и нажмите «Старт». Повторный старт публикует новый маршрут с новым временем начала. «Стоп» снимает активную сессию. Редактирование черновика само по себе не меняет опубликованную сессию.

## Контракты

| Граница | Данные и поведение |
| --- | --- |
| Редактор → Route | От 2 до 2000 упорядоченных точек WGS84 в градусах. Скорость в ядре выражена в м/с. Соседние точки должны задавать однозначную дугу длиной от 1 см. |
| Route.sample → Fix | Вход — секунды от старта. Выход — координаты, мгновенная скорость в м/с и курс в градусах по часовой стрелке от севера. Сегменты соединяются кратчайшими дугами сферы. |
| Компаньон → Vector | Remote Preferences, группа `playback`, ключ `session`. Одна строка JSON заменяет снимок целиком. Поля v1 — `v`, `target`, `startMs` (Unix-время в мс), `meanMps`, `profile`, `points` (массив пар [широта, долгота]). Удаление ключа означает остановку. |
| Vector → модуль | Entry в `onPackageReady` для первого пакета процесса. Адаптер проверяет имя пакета сессии на каждом GPS-запросе. Пустая сессия, неподдерживаемая версия и другой пакет пропускают исходный результат. |
| Модуль → LocationManager | Для успешного ненулевого `getLastKnownLocation("gps")` адаптер возвращает позицию маршрута с актуальными метками времени. Исходные проверки разрешений и доступности GPS выполняются до подстановки. |

Продолжительность равна длине маршрута, делённой на среднюю скорость. LINEAR проходит равные расстояния за равные интервалы. SMOOTH плавно разгоняется и останавливается. WAVE дважды меняет темп за маршрут. После финиша позиция остаётся в последней точке со скоростью ноль до остановки. Все процессы используют общую отметку старта. Перевод системных часов сдвигает позицию.

## Следующий этап

Для записи полноценной прогулки требуется доставка периодических координат слушателям с учётом интервалов, отмены подписки и жизненного цикла процесса. Для клиента Google Play Services понадобится адаптер Fused Location Provider. Оба адаптера могут использовать существующие Session и Route.sample. Текущая линия следует через поставленные точки, привязка к дорожной сети и сглаживание геометрии поворотов в этот этап не входят.
